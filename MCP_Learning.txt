1 Timer/Counter
① 寄存器TMOD
0-1位：设置工作模式  00是13位，01是16位  10是8为自动重装  11是T0分裂成两个8位
2位：0是Timer    1是Counter
3位：外部引脚是否控制定时器启动 (使用 P3.x 控制定时器启动) 	GATE0 = 1 时，只有 P3.2 为高电平，TR0=1 才有效 (否则即便开启了TR0 =1当没有外部信号时候Timer也不工作)
4-7位: 是T1/C1


| 功能类型    | 使用 TMOD 配置 | 时钟来源                          | 用途                 |
| ------- | ---------- | ----------------------------- | ------------------ |
| **定时器** | `C/T = 0`  | 内部时钟                          | 控制时间延迟、定时中断等       |
| **计数器** | `C/T = 1`  | **外部脉冲输入**（P3.4/T0 或 P3.5/T1） | 计算事件次数（如按钮点击、外部脉冲） |

“计数器”就是一个可以统计外部信号脉冲次数的硬件模块。每接收到一个 P3.4 引脚的负脉冲信号，TH0:TL0 加 1直到溢出为止



② 寄存器TCON
| 位号 | 位名      | 全称                            | 作用说明                                                                                                                    | 使用场景               				  |
| -- | ------- | --------------------            | -------------------------------------------- | -------------------------------------------- |
| 7  | **TF1** | Timer1 Overflow Flag   | **定时器1溢出标志位**，当 T1 计满后该位自动置 1。<br>中断方式下会自动清零     | 判断 T1 是否溢出（仅查询模式用） |
| 6  | **TR1** | Timer1 Run Control     | **控制 T1 的启动或停止**：1=启动，0=停止                                                             | 开启/停止 T1           			  |
| 5  | **TF0** | Timer0 Overflow Flag   | **定时器0溢出标志位**，T0 溢出时置 1。<br>中断方式会自动清 0                           | 判断 T0 是否溢出         			  |
| 4  | **TR0** | Timer0 Run Control     | **控制 T0 的启动或停止**：1=启动，0=停止                                                             | 开启/停止 T0           			  |
| 3  | **IE1** | External Int1 Flag           | **外部中断1 请求标志**，INT1 触发时置 1。<br>中断服务后自动清零                     | 不建议查询，自动处理         		  |
| 2  | **IT1** | External Int1 Type         | **INT1 触发方式选择**：0=低电平触发，1=下降沿触发                                            | 推荐设为 1（边沿触发）       		  |
| 1  | **IE0** | External Int0 Flag          | **外部中断0 请求标志**，INT0 触发时置 1。<br>中断服务后自动清零                      | 不建议查询，自动处理         		  |
| 0  | **IT0** | External Int0 Type         | **INT0 触发方式选择**：0=低电平触发，1=下降沿触发                                            | 推荐设为 1（边沿触发）       		  |

IEx当触发中断时自动=1，中断函数结束后自动=0。没有开启 ET0，INT0 触发仍然会让 IE0=1必须手动清0
TFx触发中断=1，在中断函数里自动清零， 你没有开启 ET0，只是让定时器计数 你在主程序中 手动轮询判断：TF0 == 1 ⚠️ 此时 TF0 不会自动清零！你必须手动清
***总结：如果没用进入中断函数，则IEx和TFx需要手动清零


THx和TLx是定时器的高8位和低8位，每次时间到了(溢出)后要手动设置THx和TLx才可以开始下一次定时工作否则会从0开始计时

计数周期时间 = 12 / 11.0592MHz ≈ 1.085 μs
定时时间（秒） = (65536 - 初值) × 1.085μs
初值 = 65536 - (延时时间 / 1.085μs)


定时器的一个数字就是一个机器周期 定时器的溢出与TFx=0或1没关系，TFx只是一个标记主要用于逻辑查询和中断

内容							是否需要你 TF1=0 清零
串口波特率发生器（方式1）		❌ 不需要 ✅
定时器中断模式				❌ 中断自动清
查询 TF1 做定时逻辑				✅ 必须手动清零

先比优先级位（高 vs 低）
如果优先级一样（都为1或都为0）
按照中断号的顺序响应  中断号小的优先（序号小，优先高）

高优先级的中断会打断正在执行的低优先级的中断，执行完优先级高的再回来执行低优先级的
不要在 ISR 里开启另一个中断，否则容易嵌套过深


如果启动了中断就要有中断函数否则程序会失控，可能死机或跳飞  开启了中断就必须写中断服务函数，哪怕里面什么都不做

3 串口通信

	定义：数据一位一位依次发送。

	典型协议：
		UART（异步串口）：TX/RX线。
		SPI：主从结构，SCLK、MISO、MOSI、SS。
		I²C：双线（SCL、SDA）。

	优点：布线简单、成本低、适合远距离通信。
	缺点：带宽较低（单线传输）。


数据通信方式
│
├── 并行通信（Parallel Communication）
│   └── 并行接口（如并口打印机、旧LCD并口）
│
└── 串行通信（Serial Communication）
    	├── 通信方式
    	│   ├── 同步串行通信（如 SPI,...）
    	│   └── 异步串行通信（如 UART,...）
    	│
    	├── 串行通信协议（逻辑层）
    	│   ├── UART（就是我们通常说的“串口通信”）
    	│   ├── SPI
    	│   ├── I²C
    	│   └── CAN、LIN（车载）
    	│
    	└── 串行接口（硬件物理层）
        	├── RS-232（UART常用的物理层）
        	├── USB（本质是高速串行）
        	├── SATA、PCIe   一些蓝牙模块


| 协议层     | 传输方式   | 接口名称         | 举例说明             |
| ------- 	  | ------ | ------------ | ---------------- |
| UART 协议 | 串行（异步） | RS-232、TTL串口 | 单片机串口通信、电脑 COM 口 |
| SPI 协议    | 串行（同步） | SPI 接口       | 连接传感器、Flash 芯片   |
| USB 协议  | 串行（高速） | USB 接口       | 键盘、U盘等外设         |
| I²C 协议    | 串行（同步） | I²C 接口       | OLED 屏幕、温湿度传感器   |


| 通信方式                 		  | 说明               				 | 举例         |
| -------------------- 		  | ---------------                                | ---------- |
| **单工（Simplex）**          | 数据只能单向流动                           | 键盘 → 电脑    |
| **半双工（Half Duplex）** | 双向通信，但同一时刻只能一方发    | 对讲机、UART   |
| **全双工（Full Duplex）**  | 双向通信，同时发送接收                  | 电话、SPI（双线） |



① (1) UART协议

| 特性        	| 描述                           					|
| --------- 		| --------------------------- 				|
| **异步通信**    | 不需要时钟线，只需 TX 和 RX 两根线       		|
| **双线全双工** | 发送和接收可同时进行（靠时序区分）           	|
| **字节为单位** | 每次发送 1 字节（8 位数据 + 起始 + 停止位）   |
| **波特率匹配** | 通信双方必须使用相同波特率（如 9600）          |


| 引脚名        | 说明       | 连接说明         |
| ---------- | -------- | ------------ |
| TXD (P3.1) | 发送引脚（输出） | 接到电脑串口接收（RX） |
| RXD (P3.0) | 接收引脚（输入） | 接到电脑串口发送（TX） |


| 位   | 内容     | 示例                  |
| --- | ------ | ------------------- |
| 起始位 | 1 位低电平 | 开始传输（0）             |
| 数据位 | 8 位数据  | 如 `0100_0001` → 'A' |
| 停止位 | 1 位高电平 | 传输结束（1）             |
总共 10 位，每一位必须按固定速率发送，这就是我们要设置波特率的原因

| 常见波特率  | 意义            |
| ------ | ------------- |
| 9600   | 每秒传输 9600 bit |
| 115200 | 更高速           |

TB8和RB8 = 1是发/收地址 = 0 是发收数据

名称	  		意义						控制方			适用串口方式
TB8			发送时第9位（地址标记）		你自己设置 ✅		方式2 / 3
RB8			接收时第9位（地址判断）		系统自动设置 ✅	方式2 / 3
方式1		8位数据，不用 TB8/RB8		


RB8 是串口硬件收到数据时自动设置的第9位标志位，不用管它，它不能写，只能读根据TB8的值而定！


SBUF寄存器只能容纳1byte
可以多次调用SBUF从而传输字符串
8051 的 SBUF 寄存器每次只接收 1 字节，多字节接收 = 多次中断 + 手动拼接
// 发送字符串
char *msg = "Hello";
while (*msg)
{
    SBUF = *msg++;
    while (!TI);  // 等待发送完成
    TI = 0;
}


UART的波特率要一致：用Timer1的溢出来设置波特率，Timer1在8位自动重装模式下：溢出的频率/32 = 波特率 （T溢出/T机械 = 256-TL1）

在 8051 串口方式1（最常用的 UART 模式）中，波特率生成器 是“硬连接”到 Timer1 的溢出频率，这是芯片内部结构决定的。

5 （1）ADC

	ADC0809
	
| 引脚     | 名称            | 类型     | 功能描述                                  |
| ------ | ------------- | ------ | ------------------------------------- |
| 1\~3   | **P1 ADD A/B/C** | 输入（地址） | 通道选择位，共支持 8 通道输入（000~~111 → CH0~~CH7） |
| 4      | **ALE**       | 输入     | 地址锁存允许信号（Address Latch Enable）        |
| 5      | **START**     | 输入     | 启动转换信号                                |
| 6      | **OE**        | 输入     | 输出使能（Output Enable），控制是否将数据输出到 D0\~D7 |
| 7      | **EOC**       | 输出     | 转换完成信号（End Of Conversion），高电平表示完成     |
| 8      | **VEE**       | 接地     | 模拟地                                   |
| 9\~16  | **IN0\~IN7**  | 输入     | 模拟电压输入通道，最多8路                         |
| 17\~24 | **D0\~D7**    | 输出     | 8位数字输出（并口）                            |
| 25     | **CLK**       | 输入     | 时钟信号（500kHz \~ 1MHz）                  |
| 26     | **VREF+**     | 输入     | 基准电压上限，常接 +5V                         |
| 27     | **VREF-**     | 输入     | 基准电压下限，常接 GND                         |
| 28     | **VCC**       | 电源     | 接 +5V                                 				|



步骤         		控制线状态变化
--------     	---------------------
1. 选通道     	设置 ADD A/B/C 三线
2. 锁地址     	ALE = 1 → 0 （上升沿触发地址锁存）
3. 启动       	START = 1 → 0（上升沿触发启动转换）
4. 等待完成   	观察 EOC 变为 高电平 → 转换完成  只读型
5. 输出数据   	OE = 1，读取 D0~D7 并口输出的数值  (电平触发)
6. 关闭输出   	OE = 0，准备下一次转换
